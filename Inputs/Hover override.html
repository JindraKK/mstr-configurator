Grid Hover Override
Replaces default MSTR white rectangle hover highlight on grid (Xtab) elements with a subtle text glow effect.

What it does:
1) Removes the default white/colored hover background on all Xtab grid cells (td.xtab-td, XtabZone, Xtab-content, scrollNode, UnitContainer layers, titlebar) by setting background to transparent !important on :hover.
2) Adds a white text-shadow glow on td.xtab-td cells when the parent VIBox container is hovered. Only affects grids, not graphs/charts.

Scope: Global — affects all grid elements on the page. Does NOT affect graphs, HTML containers, or other non-grid visualizations.

Mechanism: The MSTR default hover is a CSS :hover rule applied by MSTR stylesheet on Xtab elements (not an overlay element). It cannot be disabled via MSTR settings — only overridden with CSS !important.

Customization:
- Text glow intensity: adjust rgba alpha values in text-shadow rule
- Text glow radius: adjust px values (8px sharp + 20px diffuse)
- To disable glow and keep only removal: delete the last CSS rule block
- Works on both dark and light themes
