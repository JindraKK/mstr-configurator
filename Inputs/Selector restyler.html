SELECTOR RESTYLER v11

WHAT: Overrides MSTR DocSelector styling to match dark dashboard theme. Restyles search input box, checkbox icons (SVG sprite → CSS boxes), and search result highlighting.

WHY: MSTR DocSelectors have hardcoded light theme (white search box, SVG checkbox sprites). No native theming option exists, so we inject CSS via JS into document.head.

SCOPE: Only affects DocSelectors inside .mstrmojo-FilterBox (dashboard area). Sidebar filter panel is untouched. JS adds marker class "jk-dash-selector" to dashboard selectors only.

MSTR SEARCH QUIRK: When user types in the search box, MSTR destroys and recreates list items WITHOUT role="checkbox" attribute. CSS therefore targets both div.item[role="checkbox"] and div.item:not([role]). Items with role="radio" or role="option" are not affected.
Matched text is wrapped in tags by MSTR.

COLORS: Search box: #313131 bg, #35383A border | Checkbox unchecked: #313131 bg, #35383A border | Checkbox checked: #4A9EBF bg, white checkmark | Search highlight: #E0A030 text on transparent bg

DEPENDENCIES: MSTR Strategy One 2024 DOM structure, DocSelectors inside .mstrmojo-FilterBox, span.icon for checkbox visual.
